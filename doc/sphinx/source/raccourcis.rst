*********************
Raccourcis clavier
*********************

L'application supporte les raccourcis clavier suivants pendant une partie :

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Touche
     - Action
   * - **↑ ↓ ← →**
     - Naviguer entre les cases de la grille
   * - **1** à **9**
     - Placer un chiffre dans la case sélectionnée (ou ajouter/retirer une annotation si le mode est actif)
   * - **⟵** (Retour arrière)
     - Effacer le contenu de la case sélectionnée
   * - **A**
     - Basculer le mode annotation (on/off)
