********
Profils
********

Gestion des profils
===================

L'application supporte plusieurs profils utilisateurs. Chaque profil possède ses propres sauvegardes, statistiques et paramètres.

Créer un profil
---------------

1. Sur l'écran d'accueil, cliquez sur le bouton **"+"**.
2. Saisissez un nom de profil unique.
3. Confirmez pour créer le profil.

Supprimer un profil
-------------------

1. Survolez le profil à supprimer.
2. Cliquez sur le bouton **"X"** qui apparaît.
3. Confirmez la suppression dans la boîte de dialogue.

.. warning::
   La suppression est définitive : sauvegardes, statistiques et records du joueur sont effacés.

Paramètres
==========

Accessibles depuis la page **Profil**, les paramètres suivants sont disponibles :

**Thème :**

- **Mode clair** (par défaut) — interface claire
- **Mode sombre** — interface sombre, plus confortable en faible luminosité

**Aide au calcul :**

- **Combinaisons** (par défaut) — affiche les combinaisons possibles pour chaque bloc
- **Calculatrice** — affiche une calculatrice intégrée

Les paramètres sont sauvegardés automatiquement et appliqués immédiatement.

Statistiques
============

La page Profil affiche vos statistiques globales :

- **Parties jouées** — nombre total de parties lancées
- **Victoires** — nombre de parties résolues
- **Taux de réussite** — pourcentage de victoires
- **Temps moyen** — durée moyenne des parties
- **Niveau aventure** — progression dans le mode Aventure
- **Difficulté max** — difficulté la plus élevée tentée
- **Meilleur score** — score le plus haut enregistré

Parties en cours
================

La page Profil affiche également vos parties sauvegardées avec un aperçu visuel de la grille. Cliquez sur une carte pour reprendre la partie.

Records
=======

Les records sont partagés entre tous les profils. Le meilleur score pour chaque grille est affiché dans les menus de sélection de niveau (icône 🏆). Un record est battu si le score est supérieur, ou si le score est identique mais le temps est inférieur.
